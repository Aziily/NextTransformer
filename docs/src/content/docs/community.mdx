## Contribute

New methods, results, fixes and documentation are welcome. Start with an issue for anything larger than a fix, then
open a pull request from your fork; one method or one result per pull request. The
[contributing guide](https://github.com/Interactive-Active-AI/NextTransformer/blob/main/CONTRIBUTING.md) has the
details, and these guides cover the common paths:

- [Add a method as a plugin](../guides/plugins/)
- [Submit a result](../guides/submit-a-result/)
- [Change shared code](../guides/changing-shared-code/)

Everyone taking part is expected to follow the
[code of conduct](https://github.com/Interactive-Active-AI/NextTransformer/blob/main/CODE_OF_CONDUCT.md). Report
security issues privately, as described in the
[security policy](https://github.com/Interactive-Active-AI/NextTransformer/blob/main/SECURITY.md).

## Built on NextTransformer

Projects that build on NextTransformer's code or protocol, maintained by their authors. Their results come from their
own setups, are not audited by the NextTransformer maintainers, and are not comparable with the
[leaderboard](../results/leaderboard/).

- **[NextTransformer-V](https://github.com/Enderfga/NextTransformer-V)** by [@Enderfga](https://github.com/Enderfga) —
  a multimodal track. Frozen SigLIP2 image tokens are interleaved with text at an 8,192-token context, every
  NextTransformer method runs on them unchanged, and NextTransformer's cost ledger matches training FLOPs per token
  within 1%. Its first study, pre-registered, asks where hybrid backbones read the 2D layout of an image.

Building on NextTransformer? Share it in
[Discussions](https://github.com/Interactive-Active-AI/NextTransformer/discussions) to be listed here.
