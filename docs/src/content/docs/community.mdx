## Contribute

New methods, results, fixes and documentation are welcome. Start with an issue for anything larger than a fix, then
open a pull request from your fork; one method or one result per pull request. The
[contributing guide](https://github.com/Interactive-Active-AI/NextTransformer/blob/main/CONTRIBUTING.md) has the
details, and these guides cover the common paths:

- [Add a method as a plugin](../guides/plugins/)
- [Submit a result](../guides/submit-a-result/)
- [Change shared code](../guides/changing-shared-code/)

Everyone taking part is expected to follow the
[code of conduct](https://github.com/Interactive-Active-AI/NextTransformer/blob/main/CODE_OF_CONDUCT.md). Report
security issues privately, as described in the
[security policy](https://github.com/Interactive-Active-AI/NextTransformer/blob/main/SECURITY.md).

## Built on NextTransformer

Community projects that extend NextTransformer's code or protocol, each maintained by its authors in its own
repository. Their results come from their own setups, are not audited by the NextTransformer maintainers, and are not
comparable with the [leaderboard](../results/leaderboard/).

| Project | Area | What it does | Author | Listed |
|---|---|---|---|---|
| **[NextTransformer-V](https://github.com/Enderfga/NextTransformer-V)** | Multimodal | Trains every NextTransformer method on frozen SigLIP2 image tokens interleaved with text at an 8,192-token context, compute-matched within 1% by NextTransformer's cost ledger. Its first study, pre-registered, asks where hybrid backbones read the 2D layout of an image. | [@Enderfga](https://github.com/Enderfga) | 2026-11 |

**Add your project:** share it in
[Show and tell](https://github.com/Interactive-Active-AI/NextTransformer/discussions/categories/show-and-tell) or open a
pull request that adds a row. A listed project is public, builds on NextTransformer's code or protocol, and says so in
its README.
