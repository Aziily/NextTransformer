## 参与贡献

欢迎贡献新方法、结果、修复和文档。比修复更大的改动请先开 issue，然后从你的 fork 提交 pull request；每个 pull request 只包含一个方法或一个结果。
详见[贡献指南](https://github.com/Interactive-Active-AI/NextTransformer/blob/main/CONTRIBUTING.md)，常见路径见：

- [以插件形式添加方法](../guides/plugins/)
- [提交结果](../guides/submit-a-result/)
- [修改共享代码](../guides/changing-shared-code/)

所有参与者都应遵守[行为准则](https://github.com/Interactive-Active-AI/NextTransformer/blob/main/CODE_OF_CONDUCT.md)。安全问题请按[安全策略](https://github.com/Interactive-Active-AI/NextTransformer/blob/main/SECURITY.md)私下报告。

## 基于 NextTransformer 的项目

基于 NextTransformer 代码或协议的社区项目，由作者在各自的仓库中维护。它们的结果来自各自的实验设置，未经 NextTransformer 维护者审计，不能与[排行榜](../results/leaderboard/)直接比较。

| 项目 | 方向 | 简介 | 作者 | 收录 |
|---|---|---|---|---|
| **[NextTransformer-V](https://github.com/Enderfga/NextTransformer-V)** | 多模态 | 冻结的 SigLIP2 图像 token 与文本交错排进 8,192 长度的上下文，NextTransformer 的每种方法都不用改动就能直接训练，训练 FLOPs 由 NextTransformer 的成本账本对齐到 1% 以内。第一项研究经过预注册，探讨混合架构从哪里读取图像的二维布局。 | [@Enderfga](https://github.com/Enderfga) | 2026-11 |

**收录你的项目**：在 [Show and tell](https://github.com/Interactive-Active-AI/NextTransformer/discussions/categories/show-and-tell) 分享，或提交 pull request 在表中加一行。收录的项目需公开、基于 NextTransformer 的代码或协议，并在 README 中注明这一点。
